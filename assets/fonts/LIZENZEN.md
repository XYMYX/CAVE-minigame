# Schriften

Diese Dateien liegen bei, damit Chat-Namen und die Sprach-Hinweise auf Windows,
Linux und macOS gleich aussehen. Sie sind nicht Teil des Spiels im Sinne von
"selbst gezeichnet", sondern frei lizenzierte Schriften.

| Datei | Verwendung | Lizenz |
| --- | --- | --- |
| `NotoSans-Regular.ttf` | Latein, Griechisch, Kyrillisch, Vietnamesisch | SIL Open Font License 1.1 |
| `NotoSansArabic-Regular.ttf` | Arabisch | SIL Open Font License 1.1 |
| `NotoSansDevanagari-Regular.ttf` | Hindi (Devanagari) | SIL Open Font License 1.1 |
| `NotoSansThai-Regular.ttf` | Thai | SIL Open Font License 1.1 |
| `DejaVuSans.ttf` | Pfeile und Zusatzzeichen | Bitstream Vera / DejaVu-Lizenz |
| `wqy-microhei.ttc` | Chinesisch, Japanisch, Koreanisch | Apache-2.0 oder GPL-3 mit Font-Exception |

Die vollständigen Lizenztexte stehen in den `*-copyright.txt`-Dateien hier im Ordner.
Noto ist eine Schriftfamilie von Google. WenQuanYi Micro Hei stammt vom WenQuanYi-Projekt
und baut auf der Droid-Schriftfamilie auf. DejaVu baut auf Bitstream Vera auf.
